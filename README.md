# Multimodal Translator AI

Aplicación web de Inteligencia Artificial orientada a la traducción entre **español e inglés** mediante diferentes tipos de entrada: texto, imágenes, documentos y audio.

El proyecto integra un frontend desplegado en **GitHub Pages**, un backend desarrollado en **Python y desplegado en Vercel**, y servicios de Inteligencia Artificial mediante la API de OpenAI.

---

## Descripción

**Multimodal Translator AI** permite traducir información entre español e inglés utilizando distintos medios.

La plataforma cuenta con cuatro módulos principales:

- Chat bilingüe.
- Traducción de texto visible en imágenes.
- Traducción de documentos.
- Traducción y generación de audio.

El objetivo es demostrar la integración de diferentes capacidades de Inteligencia Artificial dentro de una sola aplicación web.
